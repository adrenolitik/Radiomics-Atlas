# Radiomics Atlas — Радиомический атлас (RADAPT)

Этот набор данных предоставляет радиомические признаки, извлечённые из **53 органов и анатомических структур** (включая паренхиматозные органы, сосуды, мышцы и кости), визуализированных на КТ-сканах области брюшной полости и малого таза **531 индивида**. Радиомические данные извлечены как из контрастно-усиленных, так и из неконтрастных изображений. Набор данных общедоступен и предназначен для научных исследований в области радиомики.

> **Название проекта:** RADAPT — Radiomics Atlas Dataset of normal Abdominal and Pelvic computed Tomography

## 🔬 Методология (подробно)

### 1. Популяция пациентов
- Ретроспективное включение 531 молодого взрослого (17–36 лет) без известных заболеваний
- КТ выполнялись по экстренным показаниям (травма, боль в животе)
- Исключались пациенты с любыми патологическими находками в отчётах или на изображениях

### 2. Протокол КТ
- Сканеры: GE / Siemens 64-срезовые
- 120 кВ, коллимация 40 мм, FOV 500×500 мм, матрица 512×512
- Реконструкция: 3.75 мм, большой корпусный фильтр
- Контраст: 370 мг J/мл, 1 мл/кг, 4 мл/с, PVP при 70 с

### 3. Сегментация
- **TotalSegmentator** (Wasserthal et al., 2023) — DL-модель для 104 структур
- Интеграция в **3D Slicer 5.2.1** для воспроизводимости
- Визуальная проверка старшим резидентом радиологии
- Исключены: ЖКТ (колон, желудок, двенадцатиперстная кишка, тонкая кишка), мочевой пузырь — из-за вариабельности наполнения/дистензии

### 4. Извлечение радиомических признаков
- **PyRadiomics** в 3D Slicer
- **Классы признаков:** First-order, GLCM, GLDM, GLRLM, GLSZM, NGTDM, Shape, Shape2D, LoG (kernel=5), Wavelet
- **Гармонизация:** Bin width 25 HU (≥8 бинов на структуру), ресэмплирование 4×4×4 мм³ (совместимость с PET/CT)
- 3 стадии проверки нормальности: отчёт + совместное описание резидентом и аттендингом + проверка мед. историй

### 5. Статистический анализ
- PCA показал однородное распределение выборки без выбросов
- Распределение признаков в NC и PVP не показывает принципиальных различий (ожидаемо для здоровой популяции)

## 🔬 Применение

Набор данных подходит для:
- Разработки и валидации радиомических моделей ML/DL
- Исследований нормальной анатомии на КТ (референсные значения)
- Обучения моделей сегментации органов (как ground truth для сравнения)
- Сравнительного анализа радиомических признаков в NC vs PVP режимах
- Бенчмаркинга алгоритмов извлечения признаков (PyRadiomics, другие)
- Интеграции с другими омиками-атласами (геномика, транскриптомика, протеомика, метаболиомика) для радиогénomики/радиопротеомики
- Использования как контрольной группы (healthy controls) в исследованиях патологий
- Внешней валидации ML-моделей, обученных на других датасетах

## ⚠️ Ограничения (из статьи)

1. **Возрастная группа:** Только молодые взрослые 17–36 лет. Возрастные изменения морфологии и тканей могут вводить вариабельность при применении к старшим популяциям. Выбор возраста сделан намеренно для представления здоровых тканей.

2. **Возможные недиагностированные заболевания:** Несмотря на тщательную проверку (отчёты, 2 эксперта, мед. истории), теоретически возможны недиагностированные состояния.

3. **Географическая/этическая специфика:** Данные из одного университета (Крит, Греция), протоколы КТ могут отличаться в других центрах.

4. **Исключённые структуры:** ЖКТ и мочевой пузырь не включены из-за непроизводимости признаков.

5. **Одна фаза контраста:** Только портально-венозная фаза (PVP). Артериальная и запаздывающая фазы не представлены.
