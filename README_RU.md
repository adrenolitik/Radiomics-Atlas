# Radiomics Atlas — Радиомический атлас

Этот набор данных предоставляет радиомические признаки, извлечённые из **53 органов и анатомических структур** (включая паренхиматозные органы, сосуды, мышцы и кости), визуализированных на КТ-сканах области брюшной полости и малого таза **531 индивида**. Радиомические данные извлечены как из контрастно-усиленных, так и из неконтрастных изображений. Набор данных общедоступен и предназначен для научных исследований в области радиомики.

---

## 📋 Описание набора данных

| Параметр | Значение |
|----------|----------|
| **Количество органов/структур** | 53 |
| **Количество пациентов** | 531 |
| **Модальность** | КТ (компьютерная томография) |
| **Область сканирования** | Брюшная полость и малый таз |
| **Типы изображений** | Контрастно-усиленные и неконтрастные |
| **Лицензия** | CC-BY-NC-ND 4.0 |

### Анатомические категории

Органы и структуры разделены на 4 основные категории:

1. **Паренхиматозные органы** (parenchymal-organs) — печень, селезёнка, почки, надпочечники, поджелудочная железа и др.
2. **Сосуды** (vessels) — аорта, полая вена, воротная вена, селезёночная вена и др.
3. **Мышцы** (muscles) — мышцы брюшного пресса, псоасничные мышцы, квадратные мышцы поясницы и др.
4. **Кости** (bones) — позвонки, ребра, тазовые кости и др.

## 🔬 Применение

Набор данных подходит для:
- Разработки и валидации радиомических моделей
- Исследований нормальной анатомии на КТ
- Обучения моделей машинного обучения для сегментации органов
- Сравнительного анализа радиомических признаков в контрастных и неконтрастных режимах
- Бенчмаркинга алгоритмов извлечения признаков (например, PyRadiomics)
